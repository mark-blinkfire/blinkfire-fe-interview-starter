# Blinkfire Frontend Interview: Round 2

## Requirements

- Node.js 20.19 or newer, or 22.12 or newer (`node -v`)
- npm
- git

## Setup

Please clone the repository (don't download it as a zip), so you can pull updates during the
interview.

```bash
git clone https://github.com/mark-blinkfire/blinkfire-fe-interview-starter.git
cd blinkfire-fe-interview-starter
npm ci
npm run dev
```

Server: http://localhost:5173

## Instructions

Find them in [instructions/INSTRUCTIONS.md](instructions/INSTRUCTIONS.md).

Your code goes in `src/components/DriversDashboard.vue`.

More instructions will be added to that file during the interview. Run `git pull` when asked.

## Other commands

```bash
npm run lint    # ESLint, with auto-fix
npm run format  # Prettier
npm run build   # production build
```
